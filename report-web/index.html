Read the uncertainty with the workload

Each point represents one independent JVM fork/block. Measurement iterations within a fork are averaged before inference. Mean intervals use Student t over fork means; paired latency ratios use matched blocks. Five forks give limited precision.

Queries include connection/session acquisition, query construction, SQL execution, full materialization and closure. A 1-to-100-row difference includes database, transfer, driver, mapping and allocation costs. Diagnostic GC/JFR runs are separate from the primary scores.

Writes measure one assigned-key, row-wise INSERT transaction including COMMIT. Reset, fixture generation and verification occur outside timing. Operation/row rates derived from latency are labeled as conversions.
